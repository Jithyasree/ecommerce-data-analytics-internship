# E-Commerce Data Analytics Internship

This repository documents my work during a 6-week Retail eCommerce Data Analyst internship.

The project focuses on applying data analytics concepts to understand eCommerce business performance, customer behavior, product performance, sales trends, and market insights.

## Internship Overview

**Role:** Retail eCommerce Data Analyst  
**Duration:** 6 Weeks  
**Focus Areas:** Data Analytics, Business Insights, Customer Behavior, Sales Analysis, and Data Visualization

Throughout this internship, I will work on weekly tasks covering different stages of the data analytics process, from developing an analytics strategy to analyzing data and generating business insights.

## Objectives

- Develop a structured eCommerce data analytics strategy
- Identify important business metrics and KPIs
- Analyze customer behavior and purchasing patterns
- Perform data cleaning and exploratory data analysis
- Conduct customer segmentation
- Identify sales and product trends
- Apply predictive analytics where relevant
- Create data visualizations and dashboards
- Generate actionable business recommendations

## Tools and Technologies

- Excel
- SQL
- Python
- Power BI
- GitHub
